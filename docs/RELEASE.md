# Release checklist

- Install and staging-test the WordPress plugin; run the authentication, membership, notification and deletion matrices.
- Create the EAS project and replace the placeholder project ID.
- Supply final official 1024×1024 icon, adaptive icon, splash assets and store screenshots.
- Test physical Android and iPhone devices: navigation, back behaviour, safe areas, keyboards, permissions, links, offline/errors, accessibility and push deep links.
- Build Android AAB and iOS archive through EAS; TAAI supplies organisation-owned Play Console and Apple Developer/App Store Connect access.
- Store metadata: “TAAI APP”; short description “Events, membership and community updates from TAAI.” Keywords: TAAI, Telugu, Melbourne, community, events, membership.
- Privacy URL: `https://taai.net.au/privacy-policy/`; support URL: `https://taai.net.au/contact-us/`.
- Describe in-app account deletion and why notification permission is requested.
- Suggested release note: “Introducing TAAI APP for TAAI events, membership, gallery and community updates.”
- Do not submit until real-device tests, policy review, final assets and store-owner approvals are complete.
